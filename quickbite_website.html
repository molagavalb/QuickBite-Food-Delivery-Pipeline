How to read the pipeline

Raw data is preserved first. Validation findings are then used to route records into publish, reject, or human-review outcomes. Only trusted rows should feed downstream analytics.

This page is a browser-side interface prototype. It does not yet connect to your Colab Python variables or SQLite database. Backend integration is the next step.
